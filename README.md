# CN4company 홈페이지

당구장 신규창업 / 설계·시공 / 매장 매매 관리 / 폐업 지원을 위한 반응형 정적 홈페이지입니다.

## 파일
- index.html : 홈페이지
- style.css : 디자인
- script.js : 모바일 메뉴
- images/ : 시공사진을 넣을 폴더

## 시공사진 넣기
현재는 모든 사진 영역을 빈 공간으로 만들어 두었습니다.
사진을 넣을 때 `images` 폴더에 사진을 넣고 `index.html`의 해당 `.placeholder` 영역을 `<img src="images/파일명.jpg">` 형태로 교체하면 됩니다.

## 배포
Cloudflare Pages 또는 GitHub Pages에 올릴 수 있습니다.
이 버전은 서버/DB 없이 동작하는 정적 홈페이지입니다.

## 수정 예정
- 이메일 주소
- 실제 시공사진 10장
- 각 프로젝트의 지역/테이블 수/공사내용
- 회사 로고가 있다면 로고 이미지
- 개인정보처리방침/사업자 정보
